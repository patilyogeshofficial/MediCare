MediCare

The Healthcare Administration Console

MediCare is a modern, full-stack healthcare administration platform designed to simplify hospital operations and improve interactions between administrators, doctors, and patients.

This project is being migrated from an existing PHP-based application into a modern Java Full Stack architecture with a React frontend and PostgreSQL database.
